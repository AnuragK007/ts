# mylib — Time Series Analysis Practicals

Install from the `mylib` subdirectory of the `AnuragK007/ts` GitHub repository:

```r
install.packages("remotes")
remotes::install_github("AnuragK007/ts", subdir = "mylib")
```

Browse the six sets in RStudio Help:

```r
?set1
?set2
?set3
?set4
?set5
?set6
```

The Help topics contain the practical code as reference examples. The examples are marked not to run automatically.
