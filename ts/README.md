# tspracticals

A reference package for six time-series practical sets.

## Help topics
- `?set1_topic1` — Moving average and smoothing methods
- `?set1_topic2` — ACF/PACF and AR(1)/MA(1)
- `?set2` — ARMA roots, ADF testing, and ARIMA forecasting
- `?set3` — SARIMA, regression, estimation, and grid search
- `?set4` — Information criteria, residual analysis, and GARCH
- `?set5` — Holt-Winters and SARIMA forecast comparison
- `?set6` — ARIMA significance, order selection, and diagnostics

The examples are displayed as copyable code. Replace the placeholder maintainer email in `DESCRIPTION` before publishing.
